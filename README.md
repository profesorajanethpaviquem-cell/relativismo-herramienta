## 📌 Descripción General

Esta herramienta educativa interactiva está diseñada para facilitar el aprendizaje del paradigma **relativista** y sus principales corrientes metodológicas: **Etnografía**, **Etnometodología** e **Interaccionismo Simbólico**. A través de un cuadro comparativo colaborativo, los estudiantes pueden:

- Comprender las dimensiones ontológica, epistemológica, axiológica y metodológica de cada corriente.
- Identificar controversias internas del paradigma relativista.
- Reconocer autores clave y sus aportes.
- Aplicar los conceptos a sus proyectos de investigación (PSIET) en Fisioterapia y Terapia Ocupacional.

La herramienta funciona **100% en el navegador**, no requiere instalación, guarda automáticamente el progreso y permite el trabajo por grupos (G1 al G14).

## 🎯 Objetivos de Aprendizaje

| Objetivo | Descripción |
|----------|-------------|
| **Ontológico** | Comprender que las realidades son múltiples, situadas y construidas social/culturalmente. |
| **Epistemológico** | Analizar la relación sujeto-objeto y la articulación teoría-práctica en cada corriente. |
| **Axiológico** | Reflexionar sobre los valores que guían la investigación cualitativa (respeto, justicia epistémica). |
| **Metodológico** | Identificar las estrategias de investigación propias de cada corriente. |
| **Aplicado** | Vincular los conceptos con los proyectos PSIET de los estudiantes. |

## 🧩 Características Principales

### 1. Cuadro Comparativo Interactivo
- **8 columnas:** Ontología, Epistemología, Axiología, Metodología, Controversias, Evidencias, Reflexión FT/TO, PSIET.
- **4 filas:** Etnografía, Etnometodología, Interaccionismo Simbólico, Análisis Integrador.
- Celdas editables con soporte para texto, imágenes y enlaces.

### 2. Trabajo por Grupos
- Selección de grupo (G1 al G14).
- Guardado automático e independiente por grupo en el navegador (localStorage).
- Posibilidad de exportar/importar respaldos en formato JSON.

### 3. Herramientas de Apoyo Didáctico
- **✨ IA sugiere contenido:** Completa celdas vacías con sugerencias académicas básicas.
- **🎓 Ejemplo completo:** Carga un modelo docente con contenido de referencia.
- **📄 Informe APA:** Exporta todo el trabajo en formato de texto con normas APA 7ª.
- **💾 Respaldo y Restauración:** Guarda y recupera el trabajo de cada grupo.

### 4. Pestañas Didácticas Adicionales
| Pestaña | Función |
|---------|---------|
| ✅ Autoevaluación | Rúbrica de 6 criterios con autocalificación (escala 1-4). |
| 🎯 Conexión PSIET | 6 preguntas guiadas para vincular la teoría con el proyecto de investigación. |
| ❓ Preguntas Frecuentes | FAQ con respuestas claras sobre relativismo. |
| 📚 Ejemplos FT/TO | Casos concretos para Fisioterapia y Terapia Ocupacional. |
| 🗺️ Mapa Conceptual | Diagrama visual de relaciones entre conceptos. |
| ✅ Checklist | Lista de verificación previa a la entrega. |

### 5. Chat Colaborativo P2P
- Conexión directa entre grupos usando **WebRTC + PeerJS**.
- No requiere servidor central.
- Cada grupo tiene un ID único para compartir y conectarse.

### 6. PWA (Progressive Web App)
- Instalable en dispositivos móviles y computadoras.
- Funciona sin conexión a internet después de la primera carga.

## 🚀 Cómo Usar la Herramienta

### Para el Docente
1. Descarga o clona este repositorio.
2. Abre el archivo `relativismo_ucshcf_final.html` en Chrome/Edge/Firefox.
3. Comparte el archivo con los estudiantes (Google Drive, WhatsApp, plataforma educativa) o despliega en GitHub Pages.

### Para los Estudiantes
1. Abre el archivo con el navegador **Chrome** (recomendado).
2. Selecciona el número de tu grupo (G1 al G14).
3. Registra los nombres de todos los integrantes y el PNF.
4. Completa el cuadro comparativo:
   - Haz clic en cada celda para escribir.
   - Usa el botón **"🎓 Ejemplo completo"** si necesitas referencia.
   - Usa el botón **"✨ IA sugiere"** para completar celdas vacías.
5. Consulta las pestañas de apoyo: Autoevaluación, PSIET, Ejemplos, etc.
6. Al finalizar, presiona **"📄 Informe APA"** y guarda el archivo `.txt`.
7. Sube el informe a la plataforma indicada por tu docente.

## 📱 Instalación como Aplicación (PWA)

### En Android (Chrome)
1. Abre la herramienta en Chrome.
2. Toca los tres puntos (⋮) → **"Instalar aplicación"**.
3. Confirma la instalación.

### En iPhone/iPad (Safari)
1. Abre la herramienta en Safari.
2. Toca el botón compartir (cuadro con flecha) → **"Agregar a pantalla de inicio"**.

### En PC (Chrome/Edge)
1. Abre la herramienta.
2. Busca el ícono de instalación en la barra de direcciones (⬇️ o +).
3. Haz clic en **"Instalar"**.
